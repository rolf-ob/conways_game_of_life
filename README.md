To download, click releases -> newest release -> download .zip
To run, right click .zip file and extract all, before running the file named main or main.exe, NOT main.py

Controls:
Move camera - WASD
Zoom in/out - scrollwheel
Place cell - left click
Drag-place cells - shift + left click
Pause - spacebar
Select/deselect cell - pause + right click
Drag-select cells - pause + shift + right click
Deselect all cells - U
Move selected cells - ctrl + WASD
Delete selected cells - backspace
Change updates/s by 1 - QE
Change updates/s by 10 - shift + QE
Update all cells once - pause + tab
Reset map - R
Toggle grid - G
Toggle debug menu - F3
